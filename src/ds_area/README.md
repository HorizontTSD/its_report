# Пайплайн исследования и прогнозирования временных рядов

## 1. Подготовка данных
- Очистка и предобработка исходных данных.
- **Заполнение пропусков:** использовать не усреднённый, но относительно простой и эффективный метод (например, интерполяция, forward/backward fill или аналогичный по контексту данных).

## 2. Кодирование категориальных признаков
- При наличии категориальных данных выполнить их кодирование (One-Hot Encoding, Label Encoding и др.)
- Убедиться, что кодирование согласовано с моделью и не вносит искажений при прогнозировании.

## 3. Исследование данных
- Анализ структуры временного ряда: выявление **аномалий, пиков, минимумов, трендов и сезонности**.
- Визуализация распределений и временных закономерностей.
- На основе анализа — **feature engineering**: создание дополнительных признаков, отражающих выявленные зависимости (например, скользящие средние, лаги, бинарные индикаторы событий и т.п.).

## 4. Подготовка данных (второй этап)
- Формирование выборок для разных типов моделей:
    - Для **деревьев решений** — создание плоской табличной структуры признаков.
    - Для **нейронных сетей (LSTM и др.)** — формирование оконных структур: временное окно, шаг, лаг и т.д.

## 5. Эксперименты
- Проведение экспериментов на **10–20% данных**.
- Расчёт точности и визуализация результатов.
- **Сохранение результатов**:
    - В директории `data/` создаются CSV-файлы формата:
        - `y_true`, `y_pred` (в `y_pred` для непредсказанных значений проставляется `None`)
        - Полная длина ряда, идентичная исходным данным
        - Колонка времени
    - В поддиректории `experiments/` сохраняются графики, метрики и `README` с результатами тестирования.

## 6. Реальное прогнозирование
- Прогнозирование на заданных интервалах времени.
- **Сохранение результатов** в `data/` с чёткой маркировкой:
    - различие между тестовыми и реальными прогнозами;
    - сохранение соответствующих CSV и графиков для дальнейшего анализа.
